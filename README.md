# Wende

Modern, mobilbarát portfólióoldal kis- és középvállalkozások weboldalainak tervezéséhez.

## Fájlok

- `index.html` — az oldal tartalma
- `styles.css` — megjelenés és reszponzív elrendezés
- `script.js` — mobilmenü, GYIK és kapcsolatfelvételi űrlap
- `assets/wende-mark.svg` — elsődleges W monogram és favicon
- `assets/wende-mark-reverse.svg` — inverz W monogram sötét háttérhez
- `assets/wende-logo.svg` — teljes vízszintes logó
