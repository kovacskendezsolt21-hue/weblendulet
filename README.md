# WebLendület

Portfólió- és értékesítési weboldal helyi szolgáltató vállalkozásoknak készített webdesign szolgáltatáshoz.

## Fájlok

- `index.html` — tartalom és szerkezet
- `styles.css` — dizájn és reszponzív nézetek
- `script.js` — mobilmenü, GYIK, animáció és Formspree űrlap
- `assets/frisspont-preview.jpg` — referenciamunka előnézete

## Publikálás

Statikus oldal, közvetlenül használható GitHub Pagesen. A kapcsolati űrlap a Formspree szolgáltatást használja.

## Fontos

Éles üzleti használat előtt ki kell egészíteni az adatkezelési tájékoztatót a szolgáltató pontos adataival, és rendezni kell a szerződéses, számlázási és adatkezelési hátteret.
